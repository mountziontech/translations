# 🙏 Chapel Library Translations

Welcome to the **Chapel Library Translations** repository! This project is dedicated to creating and maintaining **freely available, open-source translations** of Chapel Library's Christ-centered resources in as many languages as possible. 

---

## 🌍 Call for Translators & Editors

We want this to be a truly global, collaborative effort. Whether you want to fix a typo, refine a verse, or start a completely new language translation, **your contributions are welcome!**

We are actively seeking:
*   **Translation Drafts:** Starting new translations in languages not yet covered.
*   **Edits & Refinements:** Improving the flow, accuracy, or grammar of existing drafts.
*   **Reviewers:** Verifying that translations match the source intent and respect the linguistic nuances of your language.

You do not need to be a professional scholar to help—every draft, edit, and proofread brings us closer to a more accessible text.

---

## 🛠️ How to Contribute

We welcome contributions in any language! Here is how you can help:

1.  **Fork** this repository.
2.  **Create a new branch** for your language or edit (e.g., `feature/swahili-translation` or `fix/spanish-typo`).
3.  **Submit your changes** via a **Pull Request (PR)**. 

*If you are new to GitHub or git, please feel free to open an **Issue** instead, and paste your translation or feedback there. We will happily help you format it!*

---

## 📂 Repository Structure

Each language has its own dedicated folder using its standard ISO language code (e.g., `/en` for English, `/es` for Spanish):
```text
├── CONTRIBUTING.md   # Guidelines for contributing
├── README.md         # This file
├── /en               # English translations
├── /es               # Spanish translations
└── /[language-code]  # Other language folders
```
